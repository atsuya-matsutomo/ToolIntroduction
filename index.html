Tool Introduction

「リンク付きでコピー」をワンクリックにするChrome拡張たち。

JIRAチケットコピーくん

JIRAのチケットタイトルをリンク付きでコピー。

  • チケットページ・リスト表示にコピーボタンを追加
  • Slack・Discord・Google Docsに貼るとリンク付きテキストになる
  • Chrome / Arc / Edge などChromium系ブラウザ対応
Chromeウェブストア GitHub

GitHubPRコピーくん

GitHubのPR・Issueタイトルをリンク付きでコピー。

  • PR・Issueのタイトル横にコピーボタンを表示
  • リポジトリ名を前に付けるかをポップアップで切り替え
  • リッチテキスト先はHTMLリンク、プレーンテキスト先はMarkdownリンク
Chromeウェブストア GitHub

Morn Sheet Link Extension

Googleスプレッドシートの選択範囲を、名前付きのハイパーリンクとしてコピー。

  • 選択したセル範囲へのリンクをそのまま共有できる
  • Chrome / Arc など、ブラウザごとに導入
